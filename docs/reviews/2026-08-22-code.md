## Architecture Overview

**Stack:** Go (Fiber/GORM) modular monolith · React SPA · PostgreSQL + pgvector · Redis + asynq · MinIO · LLM

**Strengths:**
- Clean layered architecture (domain → application → infrastructure)
- RLS with `FORCE` + least-privilege `intivai_app` role (migration 002)
- Security-definer functions for pre-auth lookups (`login_lookup`, `validate_interview_token`)
- Single-writer WS goroutine, LLM streaming in own goroutine with ctx cancel
- Token budget (8K sliding window) with tiktoken counting
- Safety rails pinned LAST in prompt composer
- Graceful shutdown (65s > LLM 60s timeout)

## Critical Issues (4) — ✅ All Fixed

### 1. LLM Fallback Has No Retry Logic — ✅ Fixed
**File:** `backend/internal/llm/client.go:96-134`
**Severity:** 🔴 Critical
**Fix:** Primary now retries 3× with exponential backoff before falling back; fallback also retries 3× with backoff (matching `Chat()` behavior).

---

### 2. Proctoring Telemetry Missing Org Verification — ✅ Fixed
**File:** `backend/internal/interview/application/interview_service.go:488-520`
**Severity:** 🔴 Critical (Security — Cross-tenant data leak)
**Fix:** Added cross-org verification: ticket's `org_id` is resolved against the interview's org via a DB read before recording telemetry. `AUTH_FORBIDDEN` returned on mismatch.

---

### 3. Interview State Machine: Complete() Allowed From Expired — ✅ Fixed
**File:** `backend/internal/interview/domain/interview.go:250-261`
**Severity:** 🔴 Critical (Data integrity)
**Fix:** `Complete()` now rejects `StatusExpired` and `StatusCompleted` explicitly with `INTERVIEW_NOT_COMPLETABLE`, before the `StatusInProgress` guard.

---

### 4. Worker Mux Has No Panic Recovery — ✅ Fixed
**File:** `backend/cmd/server/main.go:260-272`
**Severity:** 🔴 Critical (Availability)
**Fix:** Added `workerMux.Use(...)` middleware that wraps every handler with `recover()`. Panics are logged with task type and skipped (no retry, prevents restart loops).

**Severity:** 🟡 Important

**Severity:** 🟡 Important

## Observations (7)

### 9. Worker Mux Per-Route Registration
**File:** `backend/cmd/server/main.go:260-268`
All workers register directly on the shared mux. A malformed task payload that causes `json.Unmarshal` to panic in `handle()` would not be caught.

### 10. Invitation Email Failure Silently Ignored
**File:** `backend/internal/interview/application/interview_service.go:153-154`
```go
_ = s.enqueuer.EnqueueInterviewInvitation(ctx, ...)  // error discarded
```
The candidate may never receive notification. Consider surfacing this to the recruiter.

### 11. Context Download After TX — Orphaned Row Risk
**File:** `backend/internal/context/application/context_service.go:111-118`
If MinIO upload fails after the DB commit, the context row exists but the object is missing. The index worker skips it, but the tenant sees a context in the list that cannot be retrieved.

### 12. Probe Insert — Bank Create and Interview Update Not Atomic
**File:** `backend/internal/interview/application/interview_service.go:303-309`
`bank.Create` and `ivRepo.Update` are separate transactions. If `bank.Create` fails, the interview has the probe in memory but not persisted to the question bank. On crash/resume, the probe would be missing from the bank's perspective.

### 13. Public URL TrimSuffix Edge Case
**File:** `backend/cmd/server/main.go:79`
If `publicURL` is empty string, `TrimSuffix` returns `""` and the invite URL becomes `"/interview/..."`. Should validate `publicURL` is non-empty at startup.

### 14. Frontend Malformed WS Frame Silently Dropped
**File:** `frontend/src/lib/ws.ts:94-98`
```typescript
try {
    this.opts.onFrame(JSON.parse(ev.data as string) as ChatFrame)
} catch (err) {
    console.error("Ignoring malformed chat frame", err)
}
```
Malformed server frames are logged but otherwise ignored. Consider emitting a toast notification for candidate-visible errors.

### 15. Company Context Downloaded Without Org Verification
**File:** `backend/internal/interview/application/interview_service.go:235-239`
The MinIO path includes `org_id` (`contexts/{org_id}/{hash}.bin`), providing path-level isolation. However, the storage layer does not verify the returned object matches the requesting tenant. RLS on `company_contexts` should prevent cross-tenant row access, but if RLS is misconfigured, the storage path provides a second layer of protection — but only if the path is validated.
